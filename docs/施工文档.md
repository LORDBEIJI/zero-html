## §0 一句话结论

选 **主题二「匠心传成，非遗焕新」**，做一个**多页面的数字非遗档案馆**：以**「一条线」为贯穿全站的叙事装置**，用暗黑 + 毛玻璃 + 流体渐变的现代视觉语言，包装苏绣（丝）、东阳木雕（刀）、龙泉青瓷（土）、景泰蓝（火）四大技艺，含**程序化生成的 3D 器物展馆**与**可亲手操作的一针一线 / 一刀一刻动画**。

## §4 作品概念

### 4.1 方案 A（推荐，按此施工）

**作品名**：《纹脉 · 百工录》 / **The Vein**
**主张**：**「所有的手艺，都是从一条线开始的。」**
**副题**：一针 · 一刀 · 一釉 · 一火

**叙事装置（灵魂所在）**：全站被**一条 SVG 线**贯穿。它随滚动在四个章节里变形——

```
一条丝线（苏绣）
   ↓ 被拉紧、绷成弦
一条刀痕（木雕）
   ↓ 刀锋转弯、断续成刻纹
一道釉裂（青瓷开片）
   ↓ 开片蔓延成冰裂
一圈金丝（掐丝珐琅）
   ↓ 收束、回环
又变回那条线（回到首页）
```

这条线同时是：**装饰、进度条、导航指示器、章节切换的转场动画**。技术上就是一条 `<path>` 的 `d` 在四组关键帧之间插值（用 `flubber` 之类的路径变形会引入库，**我们手写**：用 Web Animations API + 点数对齐的 path 数据插值，或用 `stroke-dashoffset` 逐段绘制 + `clip-path` 遮罩切换）。**这是整份作品里最能拿「创新鬼才」的点，也是最容易被记住的点。**

**四大技艺（章节即页面）**：

| 章 | 材料 | 技艺 | 关键词 | 视觉隐喻 |
|---|---|---|---|---|
| 一 | 丝 | 苏绣（平针 / 乱针 / 打籽） | 千丝万缕、劈丝、双面绣 | 线、光、针脚密度 |
| 二 | 木 | 东阳木雕 / 核雕 | 千刀万凿、透雕、留白 | 刀痕、木纹、负空间 |
| 三 | 土 | 龙泉青瓷 / 建盏 | 窑变、开片、雨过天青 | 釉流、冰裂、火 |
| 四 | 火 | 景泰蓝（铜胎掐丝珐琅） | 掐丝、点蓝、烧蓝、磨光 | 金丝、珐琅色块 |

**为什么这个组合最能拿分**：四种材料 → 四种完全不同的动效机制（线 / 刻 / 流 / 丝），不会让评委看到四遍同一个滚动动画；同时「丝木土火」四字本身就是一句漂亮的文案标题。

**反向点（必须避免）**：不要做成「红色喜庆国潮 + 祥云 + 金色描边」的 PPT 风。那是「中规中矩 4 分」的视觉。我们要的是**深夜博物馆**的气质：极暗、极静、极少的颜色，靠材质和光取分。

### 4.2 备选方案

- **方案 B｜像素百工**：8-bit 像素 + CRT 扫描线 + 非遗工序拆解成像素动画，反差最大、最年轻、最容易在同类作品里跳出来。风险：像素风容易显得「不高级」，素材需全手绘，工作量大。
- **方案 C｜档案体**：全站做成「博物馆藏品卡 + 档案编号 + 年份索引」的极简排版（瑞士风），靠字体、网格、留白取胜。风险：视觉冲击弱，素材分难拿满，但**最容易做出「黄金比例布局 10 分」**。

> **如果团队有 2 人以上且有人会手绘/AI 出图 → 选 A；如果只有 1 人且美术弱 → 选 C 更稳（但要把 3D 展馆做到极致，用技术补视觉）。**

## §5 视觉设计系统

### 5.1 设计基调（一句话）

> **深夜的博物馆里，只有一束顶光打在器物上。** 暗场为主，光只给器物和文字，其余全部沉入墨里。

### 5.2 色彩令牌（直接抄进 `styles/tokens.css`）

```css
:root{
  /* 墨 —— 底色四阶，不要用纯黑 #000 */
  --ink-900:#08080A;   /* 页面底 */
  --ink-800:#0D0D10;   /* 区块底 */
  --ink-700:#14141A;   /* 卡片底 */
  --ink-600:#1C1C24;   /* 描边/分隔 */

  /* 铜金 —— 主强调色（宋器铭文、金缮、掐丝） */
  --gold-100:#F4E3B2;
  --gold-300:#E3C567;
  --gold-500:#C9A227;
  --gold-700:#8A6E1A;

  /* 釉青 —— 副强调色（龙泉青瓷、雨过天青） */
  --celadon-100:#DCEDE4;
  --celadon-300:#8FBFB0;
  --celadon-500:#4E7F76;
  --celadon-700:#2C4A46;

  /* 朱砂 —— 极少量点色，只用于「火」「印章」「当前项」 */
  --cinnabar:#B23A2E;

  /* 文字 */
  --paper:#F2EDE4;            /* 宣纸白，正文 */
  --paper-dim:rgba(242,237,228,.62);
  --paper-faint:rgba(242,237,228,.34);

  /* 光 */
  --glow-gold:0 0 40px rgba(201,162,39,.18);
  --glow-celadon:0 0 60px rgba(78,127,118,.16);

  /* 玻璃 */
  --glass-bg:rgba(20,20,26,.48);
  --glass-blur:blur(24px) saturate(160%);
  --glass-border:1px solid rgba(242,237,228,.10);

  /* 栅格与节奏 —— 8pt 基准；版心按 1:1.618 切分 */
  --space-1:8px; --space-2:16px; --space-3:24px; --space-4:32px;
  --space-5:48px; --space-6:64px; --space-7:96px; --space-8:128px;
  --measure:68ch;             /* 正文行宽上限 */
  --container:1440px;

  /* 动效 —— 一套缓动走天下，禁止滥用 bounce */
  --ease-out:cubic-bezier(.16,1,.3,1);
  --ease-in-out:cubic-bezier(.65,0,.35,1);
  --dur-fast:240ms; --dur:480ms; --dur-slow:900ms;

  /* 层 */
  --z-line:10; --z-nav:100; --z-modal:1000; --z-cursor:9999;
}
```

**用色纪律**：一屏之内出现的颜色**不超过 3 个色相**（墨 + 金 + 青 = 已满额）。朱砂只允许出现在 ≤ 8% 的面积里。

### 5.3 字体

| 层级 | 字体 | 说明 |
|---|---|---|
| 标题 / 章节名 | **思源宋体 Noto Serif SC**（700/500） | 必须有宋体的「横细竖粗、有顿角」。可用 `font-display: swap` |
| 正文 | **思源黑体 Noto Sans SC**（400/500） | 正文 16–18px，行高 1.75 |
| 英文点缀 / 编号 | **Cormorant Garamond**（Italic 做装饰）+ 等宽 `JetBrains Mono` 做档案编号 | 只用于「Craft No. 003」这类小字 |
| 兜底 | `'Songti SC','SimSun',serif` | Windows 下宋体渲染差异需检查 |

> **字体文件必须子集化**（`pyftsubset` 只保留站内出现的字），否则 3 个中文字重 = 10MB+，慢网直接崩。目标：全部字体文件 ≤ 1.2MB。

### 5.4 材质与质感（这是「显卡在燃烧 10 分」的实际来源）

四层叠加，缺一层就掉档：

1. **底噪**：全屏 1 层 `feTurbulence` 生成的噪点（PNG 512×512，`opacity:.035`，`background-repeat`），消除数字感的「平」。
2. **流体渐变**：Hero 与章节转场用**手写 WebGL fragment shader**（noise + domain warping）做缓慢流动的墨/釉色晕开，**不使用任何渐变库**。降级：`conic-gradient + blur` 的 CSS 版本。
3. **毛玻璃浮层**：只用在下拉、命令面板、卡片悬停、导航条。必须带 **1px 内描边**（用 `box-shadow: inset 0 1px 0 rgba(255,255,255,.08)` 模拟光边），否则玻璃会「糊成一团」。
4. **顶光/暗角**：全局一个 `radial-gradient` 暗角（`rgba(0,0,0,.55)` 到透明），模拟博物馆射灯。

### 5.5 动效原则

- 时长 240 / 480 / 900ms 三档，缓动统一 `--ease-out`。
- **一切入场靠「显影」不靠「飞出」**：`opacity 0→1` + `translateY 16px→0` + `filter: blur(8px)→0`，绝不做 `scale(0.8)→1` 的廉价弹跳。
- 滚动驱动优先 `animation-timeline: view()`（Chrome 129 原生支持，**这是技术分白捡的分**），JS 只做兜底。
- 光标：自绘一个 8px 金色圆点 + 延迟跟随的 32px 描边环，hover 到可点元素时环放大并显示动词（「绣」「刻」「转」）。**（细节 10 分）**

## §7 三个「拿分核弹」的实现要点

### 7.1 核弹一：一条线的全站叙事（创意分核心）

**数据结构**（`src/line/morph.js`）：

```js
// 五组关键帧路径，点数必须对齐（同一套采样点，逐点插值）
const FRAMES = [
  { id:'silk',     d:'M ...' },  // 柔曲线，振幅小
  { id:'blade',    d:'M ...' },  // 折线感，带尖角（用二次贝塞尔收尖）
  { id:'crack',    d:'M ...' },  // 分叉冰裂纹（主path + 3条分支）
  { id:'gold',     d:'M ...' },  // 回环、螺旋（金丝盘绕）
  { id:'return',   d:'M ...' },  // 回到起点（与 silk 首尾相接）
];
```

实现路径（三选一，**优先 A**）：

- **A. 同点数插值**：把每组 path 用同一套参数 t 采样成 256 个点（预先离线算好写死成数组），运行时按滚动进度在相邻两组间 `lerp`。纯手写，无库，性能最好。**推荐。**
- **B. 双色交叉淡入**：两个 `<path>` 叠放，用 `stroke-dasharray` 控制显现 + `opacity` 交叉。最省事，但「变形的惊喜感」弱。
- **C. `clip-path` 遮罩推进**：一条长 path 被遮罩窗口扫过。视觉像「线在生长」，但形态不真变形。

**验收**：滚动全程线连续不断（不能出现断裂/跳变）；章节切换处线必须"穿过"视口而不是淡出；`prefers-reduced-motion` 下退化为固定线 + 无变形。

### 7.2 核弹二：程序化 3D 器物（技术分 + 素材分双杀）

```js
// 用「半径-高度」曲线旋成瓶身 —— 这就是拉坯
function makeProfile(pts){                 // pts: [[r,h], ...] 归一化 0~1
  return pts.map(([r,h]) => new THREE.Vector2(Math.max(r,0.001), h));
}
const geo = new THREE.LatheGeometry(makeProfile(PROFILE.meiping), 128); // 128 段够圆
```

- 三只器物的轮廓数据（梅瓶 / 玉壶春 / 建盏 / 珐琅瓶）**手写成数组**，每只 12–20 个控制点，加 `CatmullRomCurve3` 平滑。
- 釉面：`ShaderMaterial`，核心三件事——
  1. **菲涅尔**：`pow(1.0 - dot(normal, viewDir), 3.0)` 做边缘提亮，模拟釉的"润"；
  2. **釉流**：`fbm(uv * 3.0 + time * 0.05)` 扰动的颜色分层，模拟釉在烧制时的流动；
  3. **开片**：用 `voronoi`/`worley` 噪声取等值线做裂纹（只需在青瓷上开）。
- 光照：一盏主光（暖白）+ 一盏边缘光（青）+ 环境光极低。**不要 HDRI 贴图**（体积大），用两盏灯 + 菲涅尔就够。
- 交互：`OrbitControls` **不要用**（它是现成模块，且带默认手感）。手写：`pointerdown/move` 算 `deltaY` → 目标旋转 → `lerp` 阻尼跟随；`wheel` 改 `camera.position.z`（限幅 2.2–4.5）。**手写阻尼控制器本身就是技术分。**
- 体积：three.js 按需 `import`（`three/src/...` 精确导入，别打整个包），产物 ≤ 320KB gzip；**动态 `import()` 只在进入展馆页时加载**。

### 7.3 核弹三：细节层（按钮皆有细节 10 分）

必做清单（评委就靠这些判断「精雕细琢」还是「按钮皆有细节」）：

1. 按钮 hover：边框流光从左到右扫过（`linear-gradient` + `background-position` 动画），文字加 0.5px 字距。
2. 按钮按下：`scale(.985)` + 内阴影，时长 120ms（比入场快，手感才对）。
3. 磁吸：主 CTA 在光标 80px 内时按钮轻微向光标偏移（≤ 6px），离开回弹。
4. 链接下划线：不是实线，是**随宽度生长的细线**，且与文字有 4px 间距。
5. 图片：hover 时 `filter: brightness(1.06) saturate(1.05)` + 0.3s，绝不放大到模糊。
6. 滚动到章节：标题区一次性「显影」（blur→0 + y+16→0），全站只有这一种入场，保持统一。
7. 数字：等宽数字（`font-variant-numeric: tabular-nums`），滚动计数不抖动。
8. 自定义光标（桌面），触屏自动禁用。
9. 微音效（可选）：翻页/落款时 1 个 ≤ 80KB 的丝绸摩擦声，**默认关闭**，导航里给开关。→ 有开关就不会被判定为骚扰。
10. `:focus-visible` 必须有可见金环 2px，键盘用户全站可达。

### 8.3 慢网与降级矩阵

| 场景 | 检测 | 降级 |
|---|---|---|
| 慢网 | `navigator.connection.effectiveType` ∈ {slow-2g,2g,3g} 或 `saveData` | 跳过 WebGL 与所有视频，图片换 640px 窄版，动效只保留 fade |
| WebGL 不可用 | `canvas.getContext('webgl2')` 为空 | 展馆 → 静态高清图 + CSS 3D 翻转；流体背景 → CSS `conic-gradient` |
| `prefers-reduced-motion` | media query | 关闭视差/自动滚动/粒子，保留淡入 |
| 窄屏 < 900px | `matchMedia` | 3D 展馆 → 2D 卡片横滑；时间轴 → 纵向单列；命令面板 → 全屏列表 |
| 键盘用户 | `:focus-visible` | 全站焦点环，`Esc` 关闭一切浮层 |

### 8.4 Chrome 129 可放心用的新特性（技术分的免费弹药）

`animation-timeline: scroll()/view()`（滚动驱动动画，**核心**）、`View Transitions API`（跨页过渡）、`@starting-style` + `transition-behavior: allow-discrete`（`<dialog>` 平滑进出）、`@property`（自定义属性插值，窑变用）、`content-visibility: auto`（长页渲染优化）、`backdrop-filter`、`color-mix()`、`oklch()`、容器查询、`text-wrap: balance/pretty`、`anchor positioning`（浮层定位）、`:has()`、CSS Nesting、`light-dark()`。

> 这些只要用了，代码审查时就是「技术水平」的硬证据——**比多写 500 行 if-else 有用得多**。

### 8.5 代码规范

- 纯 ES Modules，`type="module"`，不用打包器（或仅 Vite dev）。
- 一切可复用 UI 写成 `customElements.define` 的 Web Component（`<line-progress>`、`<craft-card>`、`<command-palette>`）——**原生组件化，技术分 +10 观感**。
- 所有动画循环统一走一个 `rafLoop`（单一 `requestAnimationFrame`，避免多个循环打架）。
- 事件监听统一 `addEventListener(..., {passive:true})`，滚动用 `IntersectionObserver` 或 scroll-timeline，**禁止在 scroll 里直接读 `getBoundingClientRect()`**。
- 无 `console.log`、无 TODO、无死代码；文件顶部一行中文职责注释。

## §13 雷区（往届最容易翻车的地方）

1. **「效果很好，但没有内容」**——纯视觉站，一页只有标题和大图，内容充实度只给 2–3 分。**每个技艺必须能讲出：起源、工序步骤、地域、代表器物、术语。**
2. **「炫技但卡」**——WebGL 在主流程上常驻，滚动就掉帧。**3D 只在展馆页加载，且必须降级。**
3. **「四页长得一样」**——同一套滚动动画复制四遍。**四种材料必须有四种不同的动效机制。**
4. **「用了 Tailwind 被抓」**——代码审查会看构建产物。**一个 class 都别有。**
5. **「慢网白屏」**——字体 10MB、首图 5MB。**子集化 + WebP + 懒加载，先在 Slow 3G 下自测。**
6. **「导航只有首页」**——最容易被扣 5 分的一处，且极容易做到。**多页面是真分。**
7. **「匿名版忘了脱敏」**——直接违规。**打包脚本里加 grep 自查。**
8. **「创意方向偏了」**——做成喜庆红金祥云国潮。**我们要的是深夜博物馆的克制。**
9. **「后端吃掉两天」**——后端不计入整体评价。**先做完视觉与互动，再考虑。**
10. **「赛程记错」**——材料里时间有冲突（§2），**报名按 11/10、提交按 11/14 22:00** 提前排。
